### *The Sun Also Rises: The Visual Novel*

This repository contains the metadata and images for the visual novel transformation (pulpification) of Ernest Hemingway's book *The Sun Also Rises*.

You can read it in a few ways:

* Online at https://publicdomainpulp.com/vn/TheSunAlsoRises
* Locally at http://localhost:1929/vn/TheSunAlsoRises running https://github.com/JohnQPulp/PublicDomainPulp (ASP.NET/C#) from source
* Locally via static html file using the tool https://github.com/JohnQPulp/Pulpifier (C#) from source
